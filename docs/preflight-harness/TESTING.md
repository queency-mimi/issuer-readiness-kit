# TESTING: preflight-harness

Runner: `node --test test/*.test.ts` (Node 24 type stripping). Commands: `pnpm typecheck`, `pnpm test`, `pnpm lint`, `pnpm check`. Network tests need `PFH_NETWORK=1` and are never part of the default run.

## Layers

| Layer | Technique | Ticket |
|---|---|---|
| Taxonomy consistency | every library code mapped; every mapping target is a ReasonCode; inventory sizes (32/25/18) | smoke test today; PFH-001 against the library sources |
| Mappers | call the real library functions on hand-built, in-memory inputs, map the output, assert codes/severities/party | PFH-004/005/009 |
| Verdict derivation | precedence table | PFH-002 |
| Diff engine | hand-built verdict sets for every finding kind; determinism and order independence | PFH-006 |
| Renderers | golden files | PFH-007 |
| Adapters | replay synthetic fixtures with `fetch` replaced by a function that throws | PFH-010..012 |
| Capture | stubbed `fetch`; method/URL allow-list; secret scan of output directories | PFH-020/021/023 |
| Scenario pack | schema validation, tag rules, disclaimer present | PFH-027 |
| Differential run | real fixtures through all adapters | PFH-024 |

## Fixtures

- **Captured** (`fixtures/cases/<caseId>/`): by script only (`scripts/capture.ts`). Each file has `<name>.provenance.json` (script and commit, URLs, versions, ledger, time, `containsSecrets:false`). Mainnet: GET and unsigned `simulateTransaction` only. Testnet: PFH-021/022 may write with throwaway keys generated at runtime.
- **Synthetic** (`fixtures/synthetic/`): generated by `scripts/make-synthetic-fixtures.ts` for unit tests of loader, schemas, mappers and adapters. Provenance kind `synthetic`; they never appear in headline report numbers and never count as ground truth.
- **Spike outputs** (`fixtures/spikes/...`): raw RPC/Horizon responses with provenance for PFH-030..034.
- Addresses in fixtures are public. Synthetic strkeys come from fixed byte patterns: no private key is known. No seed or mnemonic may appear anywhere; the loader and `pnpm lint` reject seed-shaped strings.

## How to capture a new fixture

1. Add or edit the entry in `src/fixtures/catalogue.ts` (id, tags, recipe, expected codes, truth kind, tagged rationale).
2. Read-only capture of an existing public account: `node scripts/capture.ts --network testnet --accounts G...` (PFH-020).
3. Testnet seeding of a catalogue case: `node scripts/capture.ts --seed-testnet --case <caseId>` (PFH-021). It generates keys in memory, funds with Friendbot, builds the state, captures it. Check `git status` shows only `fixtures/cases/<caseId>/*`.
4. Ground truth: `--truth` submits one testnet payment (classic) and records the operation result (PFH-022). Never on mainnet.
5. `pnpm lint && pnpm test`.

## Determinism rules

Adapters strip timestamps and durations from `raw`; stellar-check's `observedAt/startedAt/finishedAt` are removed before comparison; the report's `generatedAt` is the only clock read and is excluded from `--check`. Tests never depend on library network defaults: they pass explicit sources/providers/chains.

## What the tests must not do

Contact mainnet with anything but GET/simulate; sign or submit on mainnet; call a SEP-8 approval server; execute code from `.competitors/` unless the test is explicitly the Stellar-Preflight adapter test and the directory exists (it skips otherwise).

## Coverage expectation

No numeric target. Required: each `LIBRARY_CODE_MAP` entry has at least one mapper test; each finding kind has a diff test; each catalogue case has a fixture or an explicit "not captured" line in the report.
