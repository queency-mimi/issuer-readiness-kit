## 2. MVP definition: what an investor sees in 3 to 5 minutes

A static web report (`web/`) that answers one question with recorded evidence: **"When three open-source Stellar libraries are asked whether a destination can receive an asset, do they agree, and are they right?"**

1. **Hero + status**: what the harness is, its gates (read-only on mainnet, testnet-only writes with throwaway keys, not a new library, DTC-shaped not DTC-certified), and the exact library versions under test.
2. **Diff matrix**: rows = captured testnet cases, columns = libraries, cells = the harness-derived verdict class plus the reason codes; a ground-truth column with the real Horizon operation result (`op_no_trust`, `op_line_full`, ...) or the recorded `simulateTransaction` outcome, linked to the testnet transaction hash. Applicability ("n/a") is distinct from silence.
3. **Findings**: grouped as disagreements / gaps (a library is silent) / expectation differences (a verdict differs from a trust-tagged authored expectation) / errors (a library contradicts a recorded result), each with case, libraries, codes and a one-line detail, all generated by `pfh run`.
4. **Case drill-down**: the snapshot facts (ledger, accounts, trustline flags, recorded simulations) and each library's verbatim status and reasons.
5. **DTC readiness pack page**: the 12 scenarios with their weakest-row trust tag, the evaluator's readiness against the captured fixtures, the verbatim disclaimer, and a download of the exported ScenarioPack JSON.

Every number on the page comes from `fixtures/cases/*` (testnet captures with provenance) through `pnpm demo:data`; the page labels it "recorded testnet capture, ledger N, date". Synthetic fixtures never appear in the report.

## 3. Surface choice

`web/` (Vite + React + TypeScript strict + Tailwind v4, static build). The value is a matrix you scan and drill into, which is visual and interactive; a docs site would bury it. The CLI (`pfh`) plus `README.md`/`DEMO.md` serve developers; no separate Astro site (reason: the developer surface is a CLI with `--help`, and the report itself is the documentation of results).

## 6. Risks to the demo

- Testnet resets make the captured addresses dead; fixtures remain valid evidence (snapshots with ledger numbers and tx hashes), but the explorer links stop resolving after a reset. The page says so.
- With Stellar-Preflight not executed, the matrix compares two libraries. The page shows the third column as "not run: awaiting user opt-in", never as a gap or a result.
