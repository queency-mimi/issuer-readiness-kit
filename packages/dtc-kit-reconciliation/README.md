# @sik/dtc-kit-reconciliation

Participant-side reconciliation of DTC's consolidated cash credit. Design: [DESIGN.md](DESIGN.md). Normative rules: SPEC.md section 6. Consumes the `HoldersSnapshot` JSON of the `holders-at-ledger` project as `unknown` and validates it against that project's schema; the shape is NOT defined here (see the docs/ARCHITECTURE.md contract table). Implemented 2026-11-08: `allocateConsolidatedCredit` (largest remainder, 10,000-case property test, SHA-256 checksum via @noble/hashes), `reconcile` / `expectedCredit` / `diffPositions` (one test per break code), `positionsFromHoldersSnapshot` (validated against holders-at-ledger's schema from disk, `DTC_HAL_SCHEMA`). Browser-safe entry: `@sik/dtc-kit-reconciliation/browser`. Not built: the `dtc-reconcile` CLI (DTC-035).
