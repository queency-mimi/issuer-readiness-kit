# Fixtures

- `cases/<caseId>/` captured fixtures (29 captured testnet cases as of 2026-11-08; 5 catalogued cases are not captured, see docs/FINDINGS-2026-11-08.md). Layout and rules: SPEC.md section 2.
- `synthetic/<caseId>/` hand-specified states for unit tests, generated by `scripts/make-synthetic-fixtures.ts`. Provenance kind `synthetic`; never ground truth.
- The case catalogue (34 cases) lives in `src/fixtures/catalogue.ts`.

Each captured file `X.json` has `X.provenance.json` beside it (`schemas/provenance.schema.json`). No secrets: `pnpm lint` and the loader both reject secret-seed-shaped strings.
